# Econovo Multi Product Labels Printing

## Descripción
El módulo `econovo_multi_product_labels_printing` extiende la funcionalidad del módulo `econovo_dymo_labels` permitiendo la impresión de múltiples etiquetas con cantidades personalizadas para cada producto. Este módulo es especialmente útil cuando se necesita imprimir diferentes cantidades de etiquetas para distintos productos en una sola operación.

## Características principales
- Interfaz de usuario mejorada para seleccionar productos y cantidades
- Impresión de múltiples etiquetas por producto
- Compatible con todos los formatos de etiquetas existentes
- Integración perfecta con el módulo `econovo_dymo_labels`

## Requisitos técnicos
- Odoo 17.0
- Módulo `product` (incluido en la instalación estándar)
- Módulo `econovo_dymo_labels`

## Instalación
1. Clonar o descargar este módulo en la carpeta de addons de Odoo
2. Reiniciar el servidor de Odoo
3. Ir a Aplicaciones y buscar "Econovo Multi Product Labels Printing"
4. Hacer clic en "Instalar"

## Uso
1. Ir al módulo Inventario > Productos
2. Seleccionar uno o varios productos desde la vista de lista
3. Hacer clic en "Imprimir etiquetas"
4. Ajustar la cantidad de etiquetas para cada producto en la tabla
5. Hacer clic en "Imprimir"
