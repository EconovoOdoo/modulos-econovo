# Changelog

All notable changes to this module will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [17.0.1.1.0] - 2025-05-23

### Added
- Bulk processing functionality via wizard
- Server action for processing multiple BOMs from list view
- Option to enable operation dependencies for BOMs that don't have it
- Improved error handling and user feedback
- Additional Spanish translations for new features

### Changed
- Updated documentation with bulk processing instructions
- Improved code structure and readability
- Enhanced test coverage for new functionality

## [17.0.1.0.0] - 2023-08-14

### Added
- Initial module implementation
- Button to automatically set operation dependencies based on sequence
- Spanish translations
- Demo data for testing
- Unit tests to validate functionality
- Documentation and screenshots
