## 🌍 Key Feature: GPS Geolocation

Every login is automatically geolocated:
- **City & Country** detected from IP address
- **Latitude & Longitude** coordinates
- **Google Maps link** — click to see the exact location on a map
- Uses the free **ip-api.com** service — no API key needed

---

## 🚀 Features

- 🌐 IP address capture
- 🌍 GPS geolocation (lat/lon, city, country)
- 🗺️ Google Maps link per login
- 💻 Device type (Desktop, Mobile, Tablet, Bot)
- 🌏 Browser & OS detection
- ⏱️ Timestamp & session ID
- 👑 Admin login flag
- 🏢 Company, language & timezone context
- 📋 Read-only audit log (immutable records)
- ⚡ Non-blocking — login never fails due to logging errors

## ⚙️ Installation

```bash
pip install user-agents
```

Then install the module from Odoo Apps list.
