📦 Econovo - Draft MTO/MO Control

Granular control over Manufacturing Order draft behavior
Configure when MOs should stay in draft vs. auto-confirm, based on source type (MTO/MTS/MPS/Orderpoint)

🎯 Key Features

  • Multi-level configuration hierarchy (Global → Product → User)
  • Support for 4 source types: MTO, MTS, MPS, Orderpoint
  • Maintains all Odoo native behavior (consolidation, validation, traceability)
  • Intuitive UI with radio buttons and visibility rules
  • Zero performance impact - uses cached parameters

📋 Configuration Levels

Level Location Purpose
Global Settings → General Settings System-wide default behavior
Product Product → Manufacturing tab Product-specific exceptions
User User → Preferences tab User-specific preferences

🔧 Example Configuration

GLOBAL: Custom by Source Type
✓ MTO: Keep Draft (Sales orders need review)
✗ MTS: Auto-confirm (Replenishment is automated)
✗ MPS: Auto-confirm (Planned production)
✗ Orderpoint: Auto-confirm (Min/Max rules)

PRODUCT [Critical Component]:
Policy: Always Keep Draft (Requires approval)

USER [Junior Planner]:
Policy: Always Keep Draft (Needs supervisor review)

✅ Use Cases

Conservative Company:
Review all sales-driven production, auto-confirm replenishment
Critical Product Exception:
One regulated product always needs review, others auto-confirm
Junior User Restriction:
Junior planners must have supervisor approval, seniors can auto-confirm

🚀 Installation

  1. Copy module to addons directory
  2. Update Apps List
  3. Install "Econovo - Draft MTO/MO Control"
  4. Go to Settings → Configure global policy
  5. Optionally configure product/user overrides

📚 Technical Highlights

  • 100% reliable source type detection using Odoo native fields
  • Preserves MO consolidation for non-MTO flows
  • Maintains quantity validation and traceability
  • Minimal performance overhead (3 lookups per MO)
  • Fully compatible with standard Odoo workflows
