# Econovo DYMO Labels - Etiquetas personalizadas para productos

## Descripción
El módulo `econovo_dymo_labels` está diseñado para facilitar la impresión de etiquetas personalizadas para productos en Odoo. Estas etiquetas tienen un formato de 100x70mm específicamente adaptado a los procesos de inventario y gestión de productos de Econovo, mostrando información esencial sobre cada producto y haciendo más fácil la gestión y seguimiento.

## Características principales

- Impresión de etiquetas con formato DYMO 100x70mm
- Personalización del número de etiquetas por producto
- Integración con el wizard estándar de Odoo para etiquetas de producto
- Visualización de código de barras o QR
- Soporte para mostrar precios desde diferentes listas de precios
- Fuentes personalizadas para mejor legibilidad

## Requisitos técnicos

- Odoo 17.0
- Módulo product (incluido en la instalación estándar)

## Instalación

Para instalar el módulo `econovo_dymo_labels`, sigue estos pasos:

1. Clonar o descargar este módulo en la carpeta de addons de Odoo
2. Reiniciar el servidor de Odoo
3. Ir a Aplicaciones y buscar "Econovo DYMO Labels"
4. Hacer clic en "Instalar"

## Uso

Para usar el módulo:

1. Ir al módulo Inventario > Productos
2. Seleccionar uno o varios productos desde la vista de lista
3. Hacer clic en "Imprimir etiquetas"
4. Seleccionar el formato "DYMO Etiqueta 100x70"
5. Configurar la cantidad de etiquetas para cada producto
6. Seleccionar la lista de precios deseada (opcional)
7. Hacer clic en "Imprimir"
